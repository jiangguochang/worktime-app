# 工时记录 App（iOS 可安装）

白蓝配色的个人工时记录工具：手动填上班、下班时间，自动算每天工时，一键导出表格。

## 一、怎么在 iPhone 上装

1. Windows 电脑上双击 `启动服务.bat`，窗口保持打开（窗口里会显示两个地址）。
2. iPhone 连**同一个 Wi-Fi**，用 **Safari** 打开：`http://192.168.1.253:8788/`
3. 点底部「分享」按钮 → 「添加到主屏幕」→ 添加。
4. 以后从主屏幕图标打开，全屏运行、没有地址栏，和原生 App 一样。

> 注意：必须用 Safari，Chrome 在 iOS 上不能添加到主屏幕。
> 电脑关机或关掉那个窗口后，手机上就打不开了（数据不会丢，见「数据存在哪」）。

## 二、功能

| 功能 | 说明 |
| --- | --- |
| 上午/下午分开 | 一次填一天的工时，上午一段、下午一段，各自填上下班时间 |
| 自动算时长 | 每段独立算出时长，同时给出全天合计；只填上午或只填下午也支持 |
| 跨天支持 | 某段下班早于上班时按次日计算，例如 22:00→02:00 得 4 小时，并标「跨天」 |
| 按天分组 | 首页按日期倒序，每天一卡片，上午、下午各占一行，卡片头部是全天合计 |
| 补齐空缺 | 只上半天班时，另一段显示「未填，点这里补上」 |
| 修改/删除 | 点任意一行打开面板，两段一起改；删除会先确认 |
| 今日概览 | 蓝色卡片显示今天总时长，并列出上午、下午各自的时间段 |
| 统计 | 今天、本周（周一起算）、本月、日均，以及最近 7 天上午/下午堆叠柱状图 |
| 一键导出 | CSV，表头拆出上午、下午各自的上下班时间与工时，带 UTF-8 BOM，中文不乱码 |
| 复制表格 | 制表符分隔文本，可直接粘到微信、备忘录、Numbers |
| 备份/恢复 | 导出 JSON 备份；恢复时也兼容旧版「一条记录」格式，自动整理成上午/下午 |

## 三、文件结构

```text
worktime-app/
├─ index.html              页面结构
├─ style.css               白蓝配色样式
├─ app.js                  全部逻辑（无任何依赖）
├─ manifest.webmanifest    主屏幕图标与启动配置
├─ sw.js                   Service Worker，支持离线
├─ icons/                  图标（含 iOS 主屏幕图标）
└─ 启动服务.bat            启动本地服务
```

纯原生 HTML/CSS/JS，没有构建步骤、没有 npm 依赖、不连任何服务器。

## 四、数据存在哪

记录保存在 iPhone 浏览器的 localStorage 里，**不上传任何地方**。

- 这意味着换手机、清理 Safari 网站数据、删除主屏幕图标后再添加，都可能丢数据。
- 所以：定期在「统计 → 备份」里导出 JSON，或导出 CSV 存档。
- 恢复：把 JSON 放到 iPhone「文件」App，点「从备份恢复」选择该文件。

## 五、数据结构

一天一条记录，内部拆成上午、下午两段：

```json
{
  "id": "d...",
  "date": "2026-10-24",
  "am": { "start": "09:00", "end": "12:00" },
  "pm": { "start": "13:30", "end": "18:30" },
  "note": "上午开会，下午写代码"
}
```

- `am` 或 `pm` 为 `null` 表示那半天没上班（例如下午请假）。
- 工时由时间差实时算出，不单独存储，所以改时间不会出现数字对不上。
- 同一天重复保存会提示覆盖，不会产生两条同日期记录。

## 六、已验证的内容

在 Chromium 里以 iPhone 尺寸（390×844）实测：

- 上午 09:00–12:00 + 下午 13:30–18:30 = 3 小时 + 5 小时 = 全天 8 小时，展示与导出一致；
- 只填上午（下午留空）算出 3 小时，列表下午行显示「未填，点这里补上」；
- 下午缺一个时间 → 合计显示「—」并提示「每一段的上班、下班时间要成对填写」；
- 两段都空 → 提示「上午和下午至少填一段」，不允许保存；
- 两段重叠（上午 09:00–13:00、下午 12:00–18:00）→ 可保存，但提示有重叠；
- 下午跨天 22:00→02:00 → 算 4 小时，标「跨天」；
- 4 天的今日/本周/本月/日均与明细逐条复算一致（总计 32.08 小时），CSV 合计行按列对齐（上午 12.75、下午 19.33）；
- CSV 文件头为 `EF BB BF`，含逗号的中文备注正确加引号转义；
- 旧版「一条记录」数据自动迁移：同一天两条拆成上午/下午，单条跨中午的标「跨中午」提醒拆分；
- 390px 宽度下列表、录入面板、统计页均无横向溢出。

## 七、已知限制

- 只能在电脑开机且服务运行时访问，属于局域网内使用；没有公网同步。
- 数据只在本机浏览器，没有多设备同步。
- 不是 App Store 的原生应用：Windows 环境无法编译 iOS 的 .ipa（需要 macOS + Xcode）。PWA 的安装方式和图标、启动体验与原生接近，但不出现在 App Store。
- 时长不含午休扣减逻辑：午休时间由「上午下班」到「下午上班」之间的空档自然体现，不会自动扣。
- 若要真正上架或需要多设备同步，需要单独讨论后端与开发者账号。
